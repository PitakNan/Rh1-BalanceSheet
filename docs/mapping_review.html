เขตสุขภาพที่ 1 · ตรวจสอบผังบัญชี — 3 แหล่งทางการ

ตรวจสอบการจับกลุ่มบัญชี → Planfin (P-code) และ OP / IP / P&P

เทียบการจับกลุ่มที่แดชบอร์ดใช้ กับผังบัญชีทางการ 2 แหล่งอิสระ — Mapping ผังบัญชี สป.สธ. (2026-04-10) และตาราง AccCode ในไฟล์งบทดลอง HFO เอง — พร้อมกรอบ Planfin ระดับชาติ (กองเศรษฐกิจสุขภาพฯ) เพื่อให้ CFO และทีมบัญชียืนยัน

✅
สรุป: การจับ P-code ผ่านการตรวจ 3 แหล่ง — สอดคล้อง / บัญชี (ตรงทั้ง 3 แหล่ง หรือแดชบอร์ดตรงกับผังทางการฉบับใหม่สุด) · เหลือ บัญชีที่สองแหล่งทางการเห็นต่างกัน และ บัญชี (ระหว่างหน่วยงาน/อุดหนุน) ที่ต้องยืนยัน · OP/IP ควรปรับ บัญชีให้ตรงผังทางการ

สิ่งที่พบ (สรุปสำหรับทีมบัญชี)

  • P-code — ตรวจ 3 แหล่ง: บัญชีสอดคล้อง (ตรงทั้ง 3 แหล่ง หรือแดชบอร์ด = ผังทางการ สป.สธ. ฉบับ 2026-04 ซึ่งใหม่กว่า AccCode ในไฟล์ HFO ที่เป็นเวอร์ชันปี 2564) · บัญชี สองแหล่งทางการเห็นต่าง (เช่น เงินตอบแทนพิเศษ ขรก.: สป.สธ.2026=P17 ↔ HFO2564=P20) — แดชบอร์ดยึดฉบับใหม่ · บัญชีระหว่างหน่วยงาน/อุดหนุน ที่ผัง P04–P61 ไม่ครอบ
  • OP / IP: ผังทางการระบุ OP/IP ชัดเจนเพียง 43 บัญชี — ควรแก้ให้ตรง บัญชี · ที่เหลือผังทางการไม่แยก OP/IP (กรอบ Planfin แบ่งรายได้ตามผู้จ่าย 12 กลุ่ม คือ UC/EMS/เบิกต้นสังกัด/กรมบัญชีกลาง/ประกันสังคม/ต่างด้าว ฯลฯ ไม่ใช่ OP/IP) — ค่าที่แดชบอร์ดแสดงเป็นการตีความเพื่อการบริหาร
  • ยืนยันข้ามเขต: กรอบ P-code (P04–P251) เป็นมาตรฐานระดับชาติ — ใช้ในระบบ Planfin Control (กองเศรษฐกิจสุขภาพฯ) และเขตอื่น (ขอนแก่น/นครราชสีมา) ชุดเดียวกัน

แหล่งอ้างอิงที่ใช้ตรวจสอบ (ครบรอบด้าน)

ไม่พบรายการที่ตรงกับตัวกรอง
วิธีการ — เทียบรหัสบัญชีทีละตัวกับ 2 แหล่งทางการอิสระ:
  1. สป.สธ. 2026-04: คอลัมน์ “รหัส”(P04–P61) ตรงรหัสบัญชี + “OPD/IPD” เป็นเกณฑ์ OP/IP + “REV-EXP” จำแนกผู้จ่าย
  2. HFO AccCode: GroupID(P-code) ในไฟล์งบทดลอง D5317.mdb (ระบบทางการ HFO) — เป็นแหล่งเทียบอิสระ
  3. หมวดต้นทุน LC/MC/CC/Oth จาก sheet “EXP(...)” ของ สป.สธ. · กรอบ P-code ยืนยันกับคู่มือ Planfin + กองเศรษฐกิจสุขภาพฯ (เว็บ)
ขั้นต่อไป: ทีมบัญชี/กองเศรษฐกิจสุขภาพยืนยันแถว “⚖️ เห็นต่าง”, “🔎 ต้องยืนยัน”, “⚠️ OP/IP แก้” → แก้ที่ผังต้นทาง (Mapping_Clean.xlsx / เกณฑ์ OP/IP) แล้วรันไพป์ไลน์ใหม่
