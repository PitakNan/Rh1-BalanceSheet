เขตสุขภาพที่ 1 · ตรวจสอบผังบัญชี

ตรวจสอบการจับกลุ่มบัญชี → Planfin (P-code) และ OP / IP / P&P

เทียบการจับกลุ่มที่แดชบอร์ดใช้ กับผังบัญชีทางการ สำนักงานปลัดฯ สธ. (Mapping ผังบัญชี สป.สธ. 2026-04-10) ทั้งรายรับ(P04–P61) และรายจ่าย พร้อมสิ่งที่ควรแก้ — ให้ CFO และทีมบัญชีตรวจทานอีกชั้น

✅
สรุป: การจับ P-code ถูกต้องแทบสมบูรณ์ (ตรงผังทางการ 100% ในบัญชีที่มีบรรทัดตรง) — เหลือ บัญชีที่ต้องยืนยัน (ระหว่างหน่วยงาน/อุดหนุน/สิทธิเฉพาะ) และ OP/IP ควรปรับ บัญชีให้ตรงผังทางการ · ส่วนที่ผังทางการ “ไม่แยก OP/IP” ค่าที่แดชบอร์ดแสดงเป็นการตีความเพื่อการบริหาร

สิ่งที่พบ (ต้องให้ทีมบัญชีดู)

  • P-code (การจับกลุ่ม Planfin): บัญชีตรงรหัสในผังทางการเป๊ะ + บัญชีย่อย (เงินงบ/นอกงบ) อนุมานจากรหัสฐานตรงกัน → เชื่อถือได้ · เหลือ บัญชีที่ผังทางการ P04–P61 ไม่ครอบ (รายได้/ค่าใช้จ่าย “ระหว่างหน่วยงาน/อุดหนุน” + สิทธิเฉพาะ ต่างด้าว/สถานะ) — ดูคอลัมน์ “ต้องยืนยัน”
  • OP / IP: ผังทางการระบุ OP/IP ชัดเจนเพียง บัญชี (คอลัมน์ OPD/IPD) — ควรแก้ให้ตรง บัญชี (เช่น รายได้ตรวจสุขภาพ/สร้างเสริมสุขภาพ = OP, ประกันสังคม 72 ชม. = IP) · บัญชีที่เหลือผังทางการไม่แยก OP/IP (เป็นเงินเหมาจ่าย/รวม) — ค่าที่แดชบอร์ดแสดงเป็นการตีความจากชื่อบัญชีเพื่อดูภาพบริการ ไม่ใช่เกณฑ์ทางการ
  • โบนัส — หมวดต้นทุนทางการ: ผังทางการมีหมวด LC/MC/CC/Oth (ค่าแรง/วัสดุ/ทุน/อื่น) กำกับรายจ่าย ใช้ทวนนิยาม MOE ได้ (แสดงในคอลัมน์ “หมวดต้นทุน”)
ประเภทรหัสบัญชีชื่อบัญชีP-code (ใช้อยู่ → ควรเป็น)OP/IP (ใช้อยู่ → ผังทางการ)หมวดต้นทุนหมายเหตุ / เหตุผล
ไม่พบรายการที่ตรงกับตัวกรอง
วิธีการ — เทียบรหัสบัญชีทีละตัวกับผังทางการ (sheet “(P04-P61)” ของ Mapping สป.สธ. 2026-04-10):
  1. P-code เทียบคอลัมน์ “รหัส” (P04–P61) ตรงรหัสบัญชี ถ้าไม่มีบรรทัดตรง อนุมานจากรหัสฐาน 10 หลัก
  2. OP/IP ใช้คอลัมน์ “OPD/IPD” ของผังทางการเป็นเกณฑ์ (มีเฉพาะบัญชีค่ารักษารายครั้ง) — ที่เหลือผังไม่แยก
  3. หมวดต้นทุน จาก sheet “EXP(LC,MC,CC,Oth)” (ค่าแรง/วัสดุ/ทุน/อื่น)
ขั้นต่อไป: ทีมบัญชี/กองเศรษฐกิจสุขภาพยืนยันแถว “🔎 ต้องยืนยัน” และ “⚠️ OP/IP ต้องแก้” → แก้ที่ผังต้นทาง (Mapping_Clean.xlsx / เกณฑ์ OP/IP) แล้วรันไพป์ไลน์ใหม่ ค่าจะอัปเดตทั้งแดชบอร์ด
